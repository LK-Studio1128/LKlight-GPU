# 02 v1 网格场（L1，LKlight-CUDA）

## 概述

加速线的第一个版本：把 dna 打分从"30Å 全原子对遍历"拆成**近距逐对精确 + 远距
10–30Å 受体静电场网格查表**（Uni-Dock/Vina 式"亲和力网格预计算"思想的静电版）。
一次查表替代上万次距离计算，单 swarm 提速 7×，是所有平台都可用的纯 CPU 收益。

- 里程碑意义：证明"加速不改结果"可行——网格路径与精确路径同 seed 收敛一致。
- 代码：`src/grid_dna.rs`（场构建+采样）、`src/dna.rs`（energy_exact / energy_grid 双路径）。

## 算法（核心是"为什么能查表"）

打分拆两段，关键论证是**静电在 10Å 外可线性分解**：

1. **近距 d ≤ 10Å**：仍逐对精确计算（clamp 静电 + LJ + clash 罚）。
   为什么以 10Å 为界：任何异号电荷对的 `|q_i q_j|/d²` 在 d>10Å 时都小于 clamp 阈值
   （≈0.0054 < 0.012），**clamp 永不触发** → 静电退化为纯线性 `q_i q_j/d²`；
2. **远距 10–30Å**：先对受体一次性构建标量场
   `φ(x) = Σ_i q_i / |x − x_i|²`（1Å 均匀网格，只写 10–30Å 球壳）；
   打分时对每个配体原子做**三线性插值** `q_j·φ(x_j)`——一次查表顶上万次逐对距离；
3. 配体坐标变换后近距扫描窗口收窄（Z 窗口 ±10Å），远距改为 O(配体原子数) 查表。

误差来源只有远距场的 1Å 网格插值：大体系实测平均相对误差 0.07%、有效位姿 ≤0.5%；
排序 Spearman 0.9996、前 5 名 100% 重合。

## 使用方法

与原版完全相同的命令（Score trait 默认走 energy_grid）：

```bash
cargo build --release            # CPU 网格版（任何平台）
LKlight run setup.json initial_positions_0.dat 100 dna
```
